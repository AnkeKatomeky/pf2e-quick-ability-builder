# pf2e-quick-ability-builder
Быстрое окно для создания способностей в PF2e

Гибкое окно для создания @Damage, @Check и @Template и вывод его либо сразу в чат либо в буфер обмена для дальнейшего встраивания в нужные действия 

## Установка
Этот файл модуля указать как ссылку на манифест
```
https://raw.githubusercontent.com/AnkeKatomeky/pf2e-quick-ability-builder/main/module.json
```
