# PF2e Quick Ability Builder

Небольшой модуль для Foundry VTT + Pathfinder 2e, который помогает быстро собирать inline-кнопки:

- `@Damage` для одного или нескольких пулов урона;
- `@Check` для спасбросков, навыков, Perception и flat checks;
- `@Template` для конусов, взрывов, эманаций и линий.

Окно открывается из панели инструментов токенов или горячей клавишей `Alt+B`.

## Что умеет

- Живой предпросмотр итогового HTML.
- Копирование результата в буфер обмена.
- Отправка готовой способности прямо в чат.
- Создание действия у выбранного токена или персонажа пользователя.
- Несколько частей урона в одном `@Damage`.
- Несколько проверок в одном сообщении.
- Поддержка `basic`, `showDC`, `traits`, `options`, `defense`, `against`, `area-damage`, материала, освящения и ширины линии у шаблона.

## Установка

В Foundry VTT можно указать ссылку на манифест:

```text
https://raw.githubusercontent.com/AnkeKatomeky/pf2e-quick-ability-builder/main/module.json
```

## Разработка

Модуль не требует сборки. Основные файлы:

- `module.json` - манифест Foundry;
- `scripts/main.js` - логика приложения и генерация inline-синтаксиса;
- `templates/builder.hbs` - разметка окна;
- `styles/module.css` - стили интерфейса.
